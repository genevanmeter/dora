# Zig Dataflow Example

This examples shows how to create and connect dora nodes in Zig using the C API.

## Overview

Requires zig installed.

## Compile
Build dora-node-api-c
```
cargo build -p dora-node-api-c --release
```


```
dora build dataflow.yml
```



**Run the dataflow:**

```
dora run dataflow.yml
```
